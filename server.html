BIM Lab

lab.geobim.app

Experimental IFC viewer with native IFC loading, element picking, PBR materials, clipping planes, and a georeferencing Location Editor with Cesium Ion upload pipeline.

FROST SensorThings API with PostGIS backend. Real-time bridge monitoring simulator posts acceleration, tilt, temperature & strain data every 5 seconds via MQTT.
