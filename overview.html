System architecture

Frontend
Browser · Vanilla JS
CesiumJS 1.141
Open-source WebGL geospatial rendering engine. WGS84 globe, per-frame 3D Tiles LOD selection, hardware-accelerated GPU pick buffer, HBAO, PBR Neutral tone mapping, dynamic environment maps.
Viewer core
Central BimViewer object — Ion REST asset loading, Bentley iTwin share-key integration, 4 performance presets, Google/OSM/NRW LoD2 toggles, status message system.
BIM tools
IFC entity filter (31 types), Revit category filter (34+), element picking via pickAsync(), clipping (polygon / rectangle / per-asset planes), annotations, measurements, inspection findings, BCF 2.1 export.
Rendering
Dynamic sun/shadow simulation, IBL (spherical harmonics + KTX2 cubemap), HBAO ambient occlusion. Post-processing: Bloom, Lens Flare, Vignette, Color Grading, one-click Cinematic preset (MSAA 4×).
Navigation
Orbit camera (default), first-person WASD + mouse + Xbox controller with raycast wall collision, third-person animated Cesium_Man character with Unreal-style controls and dual terrain/tile floor clamping.
Sensor integration
OGC SensorThings API v1.1 via REST + MQTT WebSocket. Real-time sparkline charts, threshold-based damage detection with animated alerts. Pegelonline water level widget (Deggendorf).
2
Backend
Hetzner VPS · Firebase
Firebase
Firestore stores annotations, area comments, measurements, saved views, and inspection findings (with JPEG thumbnails). Firebase Auth manages user sessions. Real-time cross-client sync via Firestore listeners.
FROST SensorThings server
OGC SensorThings API v1.1 at frost.christoflorenz.de. Dockerised FROST-Server + PostGIS on Hetzner VPS. Proxied via Apache SSL. 4 bridge datastreams: acceleration, inclination, temperature, strain.
PHP APIs
Server-side Ion token delivery (/api/ion-config.php), WEA turbine model discovery, damage simulation trigger, GLB asset list. Credentials never sent to the browser.

Asset hosting
3D Tiles · CDN
Cesium Ion OAuth2 v1.7
Cloud pipeline converting IFC, Revit and LAS/LAZ to streamable 3D Tiles. Token-based access control. Personal accounts connectable via OAuth2 PKCE (since v1.7.0). Token served server-side; EU infrastructure.
Google Photorealistic 3D Tiles
Global photogrammetric 3D buildings (Ion Asset 2275207). Three quality presets. skipLevelOfDetail disabled to prevent seam artifacts. Shadows off (KHR_materials_unlit — no visual effect, saves GPU).
Bentley iTwin
Infrastructure iModels loaded via share key + iModel ID. Integrates into the same asset management UI as Ion assets (visibility, opacity, z-offset).
OSM Buildings
OpenStreetMap 3D building footprints as Cesium 3D Tiles (Ion Asset 96188). Auto-disabled when Google Photorealistic tiles are active.

geobim.app
Browser-native BIM/GIS viewer · IFC · Revit · Point clouds · Live sensors · v1.7.4

CesiumJS

Open-source WebGL library for geospatial 3D (Apache 2.0). Renders a WGS84-accurate globe at any scale — from a single building to the full Earth — with per-frame level-of-detail streaming and hardware GPU readback. Used by 200 000+ developers and adopted by NASA, ESA, and major AEC firms.

Open source (Apache 2.0) WGS84 precision 3D Tiles runtime WebGL 2

Cesium Ion

Cloud pipeline that converts heterogeneous source data — IFC, Revit, LAS/LAZ point clouds, photogrammetry — into optimised, streamable 3D Tiles. Handles geometry processing, texture atlasing, feature metadata and per-token access control. Free non-commercial tier; EU infrastructure available.

IFC → 3D Tiles Revit → 3D Tiles LAS/LAZ → 3D Tiles Token-based access

3D Tiles (OGC standard)

Open specification for streaming massive, heterogeneous 3D geospatial datasets at any scale. Per-frame LOD selection, per-feature property storage, glTF payload. Adopted as an OGC Community Standard and actively developed by Cesium.

OGC Community Standard glTF payload Feature metadata Streaming LOD

Features

All features run in the browser without plugins. No build step, no desktop install. Badges mark features introduced in a specific release.

Asset import & streaming

Load IFC, Revit and point cloud assets as 3D Tiles via Cesium Ion. GLB models via direct URL. Bentley iTwin iModels via share key. Per-asset opacity slider, visibility toggle, Z-offset (–70 m to +70 m) and unload with full cleanup.

Layer manager

6 basemap options (Bing Aerial, Roads, OSM, Google Satellite), configurable terrain (World Terrain, Bathymetry, custom Ion asset), Google Photorealistic 3D Tiles (3 quality presets), OSM Buildings, NRW LoD2, custom WMS/WMTS/WFS.

BIM filtering & selection

Filter 3D Tiles by 31 IFC entity classes or 34 Revit categories with color-coded visibility. Source format is auto-detected from tile content. Left-click element selection shows all IFC/Revit properties with search and copy-to-clipboard.

Annotations & measurements

Point and polygon annotations stored in Firestore with title, category and priority. Five measurement tools: distance, area, height over terrain, vertical distance, coordinate picker. EGM96 geoid lookup for orthometric height. Firestore persistence. BCF 2.1 export.

Clipping & section planes

Draw arbitrary polygon or rectangle clipping masks on the globe. Per-asset axis-aligned section planes (X, Y, Z) with distance sliders and flip control. Terrain include/exclude toggle. Inverse clipping. Live polygon fill preview.

Rendering & post-processing v1.7.0

Dynamic sun/shadow simulation, IBL (real-time spherical harmonics + KTX2 cubemap), HBAO. Post-processing: Bloom, Lens Flare, Vignette, Color Grading (contrast, saturation, warmth). One-click Cinematic preset activates all effects at MSAA 4×.

Walk mode

First-person navigation (G key): WASD + mouse or Xbox controller, optional raycast wall collision (6 rays, throttled 10×/sec), terrain clamping. Third-person mode (V key): animated Cesium_Man character with Unreal-style controls, dual floor clamping, fan collision. Player Start via T key.

Point cloud support

Auto-detected from tile URI (.pnts) or asset metadata. Eye Dome Lighting for depth perception. Color modes: RGB, height gradient, intensity, ASPRS classification. Configurable point size, distance attenuation, geometric error scale, and three rendering presets.

Bridge inspection v1.7.4

Structured condition assessment with 14 damage types in 4 groups, 11 component categories, severity and priority. Screenshot capture on save (480×270 JPEG in Firestore). PDF report export with summary stats, component breakdown and per-finding screenshots. Anonymous demo at /bridge-inspector.

Cesium Ion connect v1.7.0

OAuth2 PKCE flow to link a personal Cesium Ion account. Browse and load private 3D Tiles and GLB assets directly from the viewer asset panel. Access token served server-side; OAuth token persisted in localStorage with automatic 90-day refresh.

Use cases

Typical applications across infrastructure, AEC, energy and public sector.

Bridge & infrastructure inspection

Structured condition assessment in a georeferenced 3D model. Inspectors place findings directly on the asset, document damage type and severity, capture screenshots, and export a PDF report. Anonymous demo available at /bridge-inspector.

Infrastructure Owner / operator BIM manager

Industrial asset management

Load large Revit plant models, filter by system (MEP, structural, architectural), annotate defects in 3D, and export BCF issues directly to authoring tools. Walk mode enables first-person facility walkthroughs.

Industry Asset manager Facility management

Site walkthroughs

First-person and third-person navigation through BIM models at their real geographic location. Useful for pre-construction design review, client presentations, and on-site orientation — including rooftop access via player-start placement.

Architecture Construction BIM coordinator

Public digital twins

Share georeferenced BIM models with contextual data: photorealistic city model, live sensor feeds, terrain, and aerial imagery. Demo mode provides 30-minute full-access sessions without login.

Public sector Municipality Urban planning

WEA shadow analysis

Parametric wind turbine shadow flicker simulation on real terrain. Adjust hub height, rotor diameter, RPM and date range. Visual output directly in the Cesium viewer for permitting documentation. Anonymous demo at /wea-shadow.

Energy Permitting authority Project developer

Live structural monitoring

OGC SensorThings API + MQTT integration for real-time sensor data visualised directly on the 3D model. Threshold-based anomaly detection triggers animated alerts. Applicable to bridges, tunnels, dams and any instrumented structure.
